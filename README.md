Write one short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock. The funniest, most original line wins. This entry's program writes a single deadpan first-person line to `/output/entry.txt` — a vacuum that mistook a sock for a crumb in costume and followed its contract.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: every run writes the exact same 66 characters.
